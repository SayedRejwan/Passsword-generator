# Advanced Password Generator

## Description
The **Advanced Password Generator** is a Python-based GUI application that allows users to generate strong and secure passwords effortlessly. With various customization options, including character types and length, it also provides a visual strength bar to indicate the security level of the generated passwords.

---

## Features
1. **Customizable Password Options**:
   - Include lowercase letters
   - Include uppercase letters
   - Include digits
   - Include special characters
   - Avoid ambiguous characters (e.g., `O`, `0`, `I`, `l`)

2. **Password Strength Indicator**:
   - Displays password strength (Weak, Medium, Strong) with a dynamic **visual bar**.

3. **Password History**:
   - Stores all generated passwords during the session.
   - Allows viewing and exporting the history to a `.txt` file.

4. **Clipboard Integration**:
   - Easily copy the generated password to the clipboard with one click.

5. **Responsive and User-Friendly GUI**:
   - Fixed-size window with a clean dark theme.
   - Intuitive layout for easy navigation.

---

   ```

3. **Run the Application**:
   ```bash

   ```

---

## How to Use
1. Open the application by running `password_generator.py`.
2. Set the desired password length and customize the character types.
3. Click **Generate Password** to create a new password.
4. View the password strength with the **visual bar** and strength label.
5. Use the following options:
   - **Copy to Clipboard**: Copies the password for immediate use.
   - **View History**: Displays all previously generated passwords.
   - **Export History**: Saves the password history as a `.txt` file.



## Requirements
- Python 3.7 or higher
- Required library:
  - `pyperclip`
